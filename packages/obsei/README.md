# obsei

Privacy-first, self-hosted, AI-native Voice of Customer. Bring your own sources, models and agents.

> **obsei is being rebuilt.** 0.1.0 is a new codebase and is not compatible with 0.0.x.
> The last 0.0.x release (0.0.15) stays available on PyPI.

```bash
uvx obsei --version
uvx obsei doctor
uvx obsei schema   # Feedback Record JSON Schema
```

See the [project README](https://github.com/obsei/obsei) and [roadmap](https://github.com/obsei/obsei/blob/master/ROADMAP.md).
