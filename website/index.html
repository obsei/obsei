Voice of Customer without violating privacy

Open-source, self-hosted, AI-native feedback analytics. Reviews, tickets, calls, surveys and communities in one place, in every language, with PII redacted before anything is stored.

Get started Open the demo 
uv tool install --prerelease allow "obsei[mcp]"
obsei init && obsei run

Private by design

Runs inside your infrastructure. Checksum-validated PII redaction for the Americas, Europe, Asia-Pacific, India and Africa in any script, pseudonymous authors, an encrypted database and air-gapped egress by default.

Bring your own

App stores, helpdesks, calls, SQL warehouses, webhooks, communities and any REST or MCP source. Any OpenAI-compatible model: Ollama, vLLM, Azure OpenAI, or Bedrock and Vertex via LiteLLM.

AI-native

A read-only MCP server and a Claude plugin, so agents answer "what are customers saying?" with cited, redacted evidence. Ask questions in any language.

Themes you can trust

Stable themes with trends, near-duplicate detection, k-anonymous views and a knowledge graph that links issues to sources, languages and intents.

obsei provides controls that support compliance with laws such as the GDPR, India's DPDP Act, Brazil's LGPD and California's CCPA. It makes no compliance claims; you remain the data controller.
