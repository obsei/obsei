Frequently asked questions

What is obsei?

obsei is an open source, self-hosted Voice of Customer pipeline. It collects customer feedback from app stores, support desks, communities, files and your own databases, removes personal data as it arrives, labels and groups it into themes across languages, and sends what matters to Slack, Jira, Linear, a warehouse or your AI agents.

Is obsei free?

Yes. obsei is Apache-2.0 licensed, with no paid tier, no open-core split and no hosted version. You run it on your own laptop or servers.

How is obsei different from Enterpret, Unwrap and other feedback analytics tools?

Hosted feedback tools process your customers' text on their servers. obsei runs on your infrastructure, strips PII before any model sees the text and can label feedback with a model on your machine, so customer data doesn't have to leave your network.

Does obsei send customer feedback to an LLM?

Not by default. Redaction runs at ingest, the local classifier runs inside obsei, and the default egress policy blocks model and sink traffic to outside hosts. Feedback is sent to a model or service only if you configure it and allow its host.

Which feedback sources does obsei support?

20 built in: the App Store, App Store Connect, Google Play, Zendesk, Freshdesk, Intercom, Gong, GitHub issues, Hacker News, Bluesky, YouTube, RSS, email (IMAP), SQL databases, CSV and JSON Lines files, file drops, webhooks, any REST API and any MCP tool. Reddit and Typeform source plugins install from the GitHub repository.

Can AI agents like Claude, Cursor or Codex use obsei?

Yes. obsei includes an MCP server, listed in the MCP Registry, and plugins for Claude Code, Codex, the GitHub Copilot CLI and Gemini CLI that install from its GitHub repository. Cursor and VS Code add the server with an install button. Agents search, count and read redacted feedback with record ids to cite. Customer text is marked untrusted, and the only write, a proposed issue, waits for a person to approve it.

How accurate is the classifier?

On obsei's 136 synthetic demo records in 11 languages, the default model, bge-m3-zeroshot-v2.0, scored 0.82 on intent, 0.90 on sentiment and 0.91 on team routing. The expected answers come from the demo's issue definitions, not human review. Run obsei eval on a labelled sample of your own feedback to measure it on your data and pick confidence cutoffs.

How do I install obsei?

Run uv tool install "obsei[recommended]", then obsei init and obsei try in an empty folder; pip install "obsei[recommended]" works too. The first run downloads the local model once (about 1.2 GB) and needs no API keys. The container image ghcr.io/obsei/obsei has the sources and sinks but not the local classifier.
