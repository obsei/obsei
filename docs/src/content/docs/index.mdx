## Why obsei

<CardGrid>
  <Card title="Private by design" icon="approve-check">
    Checksum-validated PII redaction for the Americas, Europe, Asia-Pacific, India and Africa in
    any script, optional name redaction, pseudonymous authors, an encrypted database and
    air-gapped egress by default.
  </Card>
  <Card title="Bring your own" icon="puzzle">
    App stores, helpdesks, calls, SQL warehouses, webhooks, communities and any REST or MCP
    source. Any OpenAI-compatible model, from Ollama to Azure OpenAI, or Bedrock and Vertex via
    LiteLLM.
  </Card>
  <Card title="AI-native" icon="rocket">
    A read-only MCP server and a Claude plugin, so agents answer "what are customers saying?"
    with quotes and record ids, never author identities.
  </Card>
  <Card title="Every language" icon="translate">
    Feedback is classified and quoted in its own language; a local multilingual model groups the
    same issue across 50+ languages.
  </Card>
</CardGrid>
