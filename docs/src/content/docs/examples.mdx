Each example is a complete, commented `obsei.yaml` in the
[`examples/`](https://github.com/obsei/obsei/tree/master/examples) folder. The header of each file
lists the extras to install, the environment variables it reads and how to run it. Every example
is loaded with the real config loader in CI, so the keys match the current release.

```bash
git clone https://github.com/obsei/obsei && cd obsei
export OBSEI_DB_KEY="$(openssl rand -hex 24)" OBSEI_PSEUDONYM_SALT="$(openssl rand -hex 24)"
obsei try -c examples/social-listening.yaml        # preview redacted records; nothing stored or sent
obsei run -c examples/social-listening.yaml
```

Copy a file to `obsei.yaml` in your project and replace the placeholder ids, hosts and names.
Secrets are always read from environment variables.

## Multilingual ticket routing with a decision model

Zendesk and Freshdesk tickets in any language, labelled on a CPU by Julia-1, a 144M decision model
served by llama.cpp: spam is filtered out first, then one request per ticket answers sentiment,
intent (with descriptions), an urgency score and a yes/no refund question. Answers below their
cutoff go to a local Ollama chat model. Ordered [routes](/guides/routing/) then pick one destination
per ticket: uncertain tickets go to a review channel, confident urgent bugs open a Jira issue and
page on-call, billing and refund requests go to the billing channel, and the rest lands in Parquet.
A CSV of eight sample tickets in seven languages lets you try it locally:
`obsei try -c examples/decision-routing.yaml -p sample --enrich --limit 8`.
