# Icons

Used by the sources and sinks tables (`.i-*` classes in `src/styles/brand.css`) and by
`brand/integrations-light.svg` and `brand/integrations-dark.svg` in the repository README.

- Brand logos (`zendesk`, `intercom`, `github`, `bluesky`, `jira`, `linear`, `modelcontextprotocol`,
  `ycombinator`, `reddit`, `apacheparquet`) are from [Simple Icons](https://simpleicons.org)
  16.32.0, CC0-1.0. They are trademarks of their owners, used only to show which services obsei
  connects to. Brands that restrict their marks or have no usable icon (Apple, Google Play,
  YouTube, Microsoft, Slack, Freshdesk, Gong, Typeform) use a generic icon.
- Generic icons are from [Lucide](https://lucide.dev) 1.49.0, ISC License, Copyright (c) 2026
